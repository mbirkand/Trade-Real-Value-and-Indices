1Data and scope

  • Source: FAO trade data (June 2026 extract), 2000–2024: import and export quantity and value by country × CPC item × year.
  • Base period 2014–2016 = 100.
  • Imports and exports are calculated separately throughout. A country can have results for one flow and not the other.
  • Values are in thousand USD, quantities in tonnes, unit values in thousand USD per tonne (shown as $/t on the other pages).
  • Every measure is calculated for items (one country × item) and for aggregates (item groups, for single countries and for regions).
Data snapshot. The trade data were extracted in June 2026, so results run up to 2024. They may not match the current data in SWS exactly.

2Preparing the data

  1. Reshape to one row per country × item × year with four columns: import Q, import V, export Q, export V.
  2. Remove live animals (CPC 021…). They are reported in head, not tonnes, so their unit values are not comparable.
  3. Fix one-sided zeros: if Q = 0 but V > 0, Q is set to missing; if V = 0 but Q > 0, V is set to missing. The other side still counts in its own index.
  4. A valid observation is one with Q > 0 and V > 0 — enough to compute a unit value.
Nothing is filtered out for size. Very small records (Q < 10 t or V < 10 thousand USD) are counted and reported but kept. There is no coverage rule and no minimum number of base years.

3Base unit value (2014–2016)

The 2014–16 price of one country × item × flow. It is the denominator of the item unit value index (7.1) and the price that turns quantities into real values (8).

UVt = Vt ÷ Qt base UV = (UV2014 + UV2015 + UV2016) ÷ 3simple average of the three yearly unit values

When a base year is missing

A missing year is rebuilt from the country's nearest own year, moved by the parent group's rate of change. Only the change is borrowed; the country keeps its own price level.

UVmissing = UVanchor × (parent UVmissing ÷ parent UVanchor)
  1. Fill 2015 first — from 2016 if the country has it, otherwise from 2014.
  2. Then fill 2014 and 2016 from 2015. Every remaining gap is a single step.
  3. If no parent group has a unit value for both years of a step, the parent's own unit value for the missing year is used.
  4. If the country has no base-year data at all, the parent group's base UV is used as it is.
This filling applies only to the base unit value — and so to the unit value index and to real values. The value and quantity indices are never filled from larger areas (5.1, 6.1).

Parent groups

  • The country's regional groups, smallest first: tier 1 → tier 2 → tier 3 → global (all countries).
  • A group's unit value for a year is pooled: ΣV ÷ ΣQ over its member countries.
  • Not used as parents: EU (27), Australia and New Zealand, LDCs, landlocked and small-island developing states, LIFDCs, net food-importing developing countries, and all "excluding intra-trade" groups.
  • No outlier filtering is applied to base unit values.

Every flow records where its base UV came from: country (all three years own data), imputed (some years rebuilt) or the group name / global (taken from a group).

4Group totals aggregates

Aggregates are not averages of item results. Items are first summed into item groups, and countries into regions; every aggregate in parts A and B is then calculated on these totals.

Country × item group

Group valuet = Σ Vi,tthousand USD Group quantityt = Σ Qi,t × factoritonnes Group real valuet = Σ Qi,t × base UVithousand USD at 2014–16 prices
  • The item factor applies to quantity.
  • The factor is 1 for almost every item. Only a limited number use another factor — 37 items, in 44 of 2,354 item × group pairs — to convert them to a common equivalent, for example rice, milled equivalent, cassava equivalent, some milk groups (cheese, butter and ghee, whey, condensed and dry milk) and some meat groups.
  • An item can belong to more than one group.
  • An item with no data in a year drops out of that year's sum. An item reported with value but no quantity counts in the group value, but not in the group quantity or real value.

Region × item group

  • Sum of the country × item group totals over member countries with Aggregation = TRUE.

Base of every aggregate index

  • The average of the group total over 2014–16 — not the sum of the items' own bases. An item or country that enters the group after the base adds to later years but not to the base.

Example used for aggregates

One country, a group of two items: olive oil and wheat. Base years are identical for simplicity. Every price rose by 10%; olive oil volume halved, wheat volume rose by half.

5Value index

How the trade value in current US dollars changed since 2014–16. It moves with both prices and volumes.

5.1Items country × item

Value indext = Vt ÷ mean(V2014–16) × 100
Denominator
The average value over the country's own valid base years — one, two or three of them. Never filled from a group.
No index when
The country has no valid base year for the item and flow.
Example
Wheat: 360 ÷ 197.3 × 100 = 182.4 — the 2020 import bill is 82% above the base.
If only one base year exists and it is small, every later year is divided by that small number. A single 2014 record of 2 thousand USD turns an ordinary 2,000 thousand USD year into an index of 100,000.

5.2Aggregates item groups and regions

Value indext = Group valuet ÷ mean(Group value2014–16) × 100
Weights
None needed: dollars of different items can be added directly.
Example
Olive oil + wheat: 660 ÷ 800 × 100 = 82.5.
The value total includes value-only items; the quantity and real value totals do not. A group can therefore have a large value base and an almost empty quantity base (for example Colombia, crude materials n.e.s. exports: base quantity 0.26 t against 1.38 bn USD of value).

6Quantity index

How the traded tonnage changed since 2014–16. Prices play no part.

6.1Items country × item

Quantity indext = Qt ÷ mean(Q2014–16) × 100
Denominator
The average quantity over the country's own valid base years, as for the value index. Never filled from a group.
No index when
The country has no valid base year for the item and flow.
Example
Wheat: 1,500 ÷ 1,000 × 100 = 150 — 50% more tonnes than in the base.
Same weakness as the value index. Bangladesh soya bean oil exports have only 2014 (0.002 t), so 22,000 t in 2019 gives a quantity index of 1,100,000,000.

6.2Aggregates item groups and regions

Quantity indext = Group quantityt ÷ mean(Group quantity2014–16) × 100
Weights
Tonnes. A tonne of olive oil and a tonne of wheat count equally.
Example
Olive oil + wheat: 1,575 ÷ 1,150 × 100 = 137.0 — 37% more tonnes, because cheap wheat grew while expensive olive oil shrank.
Meaningful only for groups of similar products. For a mixed group it mostly tracks the heaviest, cheapest items. Use the real value index (9.2) as the volume measure for a group.

7Unit value index

How prices changed since 2014–16.

7.1Items country × item

Unit value indext = UVt ÷ base UV × 100UVt = Vt ÷ Qt
Denominator
The base UV from section 3. Unlike the value and quantity bases, it may be rebuilt or taken from a group.
No index when
The year has no valid observation (Q > 0 and V > 0), or no base UV could be built.
Example
Wheat: 240 ÷ 200 × 100 = 120 — 20% more per tonne than in the base.
Value index ≠ quantity index × unit value index ÷ 100. In the example, 150 × 120 ÷ 100 = 180, not 182.4. The base UV is the average of the yearly unit values (200 $/t), not mean value ÷ mean quantity (197.3 $/t), and it may come from a group while the other two bases cannot.

7.2Aggregates item groups and regions

The price change of the group, holding the item mix fixed at this year's quantities. It is derived from the value index (5.2) and the real value index (9.2).

Unit value indext = Value indext ÷ Real value indext × 100   = (Group valuet ÷ Group real valuet) ÷ (base value ÷ base real value) × 100
Reads as
This year's quantities at this year's prices against the same quantities at base prices — price change only. The second factor rescales the base period to 100.
No index when
Either the value index or the real value index is missing.
Example
Olive oil + wheat: 82.5 ÷ 75.0 × 100 = 110.0 (also 660 ÷ 600 = 1.10) — prices up 10%, exactly as for each item.
Why not group value ÷ group tonnes? In the example that gives 696 $/t in the base and 419 $/t in 2020 — a 40% "price fall", while every price rose by 10%. The drop is only the shift from olive oil to wheat.
Part BReal valuesTrade at constant 2014–16 prices, and the volume index built on it. Each is shown for items, then for aggregates.

8Real value

This year's volume priced at 2014–16 prices: the value the trade would have had if prices had not changed.

8.1Items country × item

Real valuet = Qt × base UVthousand USD at 2014–16 prices
Inputs
The year's quantity and the base UV from section 3.
Calculated when
Both exist — including flows whose base UV was rebuilt or taken from a group, and flows that have no quantity index.
Example
Wheat: 1,500 t × 200 $/t = 300 thousand USD. The actual value is 360, so 60 of it is the price rise.

8.2Aggregates item groups and regions

Group real valuet = Σ Qi,t × base UVithousand USD at 2014–16 prices
Coverage
Only items with a quantity and a base UV; value-only items are left out. Regions sum their member countries (section 4).
Example
Olive oil + wheat: 75 × 4.0 + 1,500 × 0.20 = 600 thousand USD, against 660 actual — 60 of it is the price rise.

9Real value index

How the trade volume changed since 2014–16, with each item weighted by its 2014–16 price.

9.1Items country × item

Not produced. With one fixed base UV it would cancel out and leave exactly the quantity index: (1,500 × 200) ÷ (1,000 × 200) × 100 = 150. Real value becomes its own measure only when different items are added up.

9.2Aggregates item groups and regions

The volume index for a group.

Real value indext = Group real valuet ÷ mean(Group real value2014–16) × 100   = Σ(Qi,t × base UVi) ÷ mean(Σ Qi × base UVi)2014–16 × 100
Weights
Each item's base UV. A tonne of olive oil (4,000 $/t) counts 20 times a tonne of wheat (200 $/t).
Example
Olive oil + wheat: 600 ÷ 800 × 100 = 75.0 — volume fell by 25%, because the lost olive oil was worth more at base prices than the extra wheat.
Not the same as the quantity index (6.2). In the example the quantity index says +37% and the real value index says −25%. The two agree only when the group has one item, all items have the same base UV, or the item mix does not change.

How the checks work

Applied to every item index value: quantity, value and unit value.

Reproduction

    Flags

    • Critical  index above or below
    • Warning  index above or below , or a year-on-year change of more than ×
    • Index = 0 (no trade) is not flagged.

    Order of importance

    • Critical before warning.
    • Then base problems → one-off years → negligible flows → sustained change.
    • Then larger trade first (average value of the latest five years).

    Finding the cause

    • Each flagged value is split into three parts:
      • Base — base average vs the level around it (2011–13 and 2017–19).
      • One-off — this year vs the surrounding years (±3).
      • Sustained — the surrounding years vs the level around the base.
    • Unit values are compared with other countries instead (median of the same item and year, at least 5 countries).
    • The largest part names the cause.
    • Negligible = quantity below t or value below thousand USD.

    How the checks work

    Reproduction

      Flags

      • Same thresholds as for items: critical above 5,000 or below 1; warning above 1,000, below 10, or a year-on-year change of more than 10×.
      • Index = 0 (no trade) is not flagged.

      Members

      • Country aggregate = its items. Region aggregate = its member countries.
      • The change between the 2014–16 average and the flagged year is split across members.

      Finding the cause — in this order

      • Negligible base: the group's 2014–16 average is below 10 t or 10 thousand USD.
      • Coverage: at least half of the year's total comes from members with no 2014–16 data, or at least half of the base comes from members missing that year.
      • One member: a single item or country explains at least half of the change. Its own diagnosis is shown.
      • Otherwise the aggregate series itself is split into base / one-off / sustained parts, as for items.

      Order of importance

      • Critical before warning → base → coverage → one member → one-off years → sustained change → larger trade.

      Why real value and value diverge

      Real value = quantity × 2014–16 base unit value, so real value ÷ value = base unit value ÷ this year's unit value. A large gap means either the base unit value or that year's quantity/value is off — or prices really moved.

      Start here — most important issues

      Critical first, then base unit value problems (they affect every year), then the largest gap between real value and value in thousand USD. Click a row to see the core data and the real value it produces.

      How the checks work

      Rules

      • Critical  real value more than 100× the value, or less than 1/50 of it.
      • Warning  real value more than 10× the value or less than 1/10 of it, or a 10× jump in the ratio from one year to the next.
      • These are exactly the unit value index flags seen from the real value side (ratio = 100 ÷ unit value index).

      Cause

      • The base unit value is compared with other countries' base unit value for the item.
      • The year's unit value is compared with other countries' unit value that year.
      • Whichever is further off names the cause; if other countries moved too, it is a real price change.
