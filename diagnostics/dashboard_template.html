Indices — aggregates only

2Value index item groups and regions

How the trade value of a group in current US dollars changed since 2014–16. It moves with both prices and volumes.

Value indext = Aggregate valuet ÷ mean(Aggregate value2014–16) × 100
Aggregate
A country × item group, or a region × item group. The aggregate value is the sum of the items' values (section 6).
Denominator
The average of the aggregate value over the 2014–16 years in which the aggregate has a value.
No index when
The aggregate has no value in any base year, or its base average is 0.

3Quantity index item groups and regions

How the traded tonnage of a group changed since 2014–16. Prices play no part; every tonne counts the same.

Quantity indext = Aggregate quantityt ÷ mean(Aggregate quantity2014–16) × 100
Aggregate
The sum of the items' tonnes, each multiplied by its item factor (section 6).
Denominator
The average of the aggregate quantity over the 2014–16 years in which the aggregate has a quantity.
No index when
The aggregate has no quantity in any base year, or its base average is 0.
An item reported with value but no quantity counts in the value index but not in the quantity index. In groups where most of the trade has no quantity, the quantity index covers only a small part of the group.

Supporting steps

5Base unit value (2014–2016)

The 2014–16 price of one country × item × flow. It is the price that turns quantities into real values (section 4).

UVt = Vt ÷ Qt base UV = (UV2014 + UV2015 + UV2016) ÷ 3simple average of the three yearly unit values

When a base year is missing

A base year counts as the country's own data when it has both a quantity and a value above zero. A year without own data is estimated from a year that has it: take the country's own unit value in that year and move it up or down by as much as the parent group's unit value moved between the two years.

Only the group's change is used, not its price. The country keeps its own price level, which can be higher or lower than its neighbours' for good reasons. The flip side: if the country's own year is wrong, the estimated years copy the error.

The country itself is left out of the group. The parent group's unit values used for a country are calculated from the other member countries only (leave-one-out). Otherwise the country's own record — often a large share of a small group — would move the group's price and feed back into its own estimate. If no other member has data for both years, the next group up is used.

Changed on 22 October 2026. Until then the parent group's unit values included the country being estimated.
UVmissing = UVanchor × (parent UVmissing ÷ parent UVanchor)parent = the other member countries
  1. Fill 2015 first — from 2016 if the country has it, otherwise from 2014.
  2. Then fill 2014 and 2016 from 2015. Every remaining gap is a single step.
  3. If no parent group has a unit value for both years of a step, the parent's own unit value for the missing year is used.
  4. If the country has no base-year data at all, the parent group's base unit value is used as it is.

Parent groups

  • The country's regional groups, smallest first: tier 1 → tier 2 → tier 3 → global (all countries).
  • A group's unit value for a year is pooled: ΣV ÷ ΣQ over its member countries, leaving out the country being estimated.
  • Not used as parents: EU (27), Australia and New Zealand, LDCs, landlocked and small-island developing states, LIFDCs, net food-importing developing countries, and all "excluding intra-trade" groups.
  • No outlier filtering is applied to base unit values.

Every flow records where its base unit value came from: country (all three years own data), imputed (some years rebuilt) or the group name / global (taken from a group).

6How aggregates are built

Aggregates are not averages of item results. Items are first summed into item groups, and countries into regions; the aggregate indices and real values are calculated on these sums.

Country × item group

Aggregate valuet = Σ Vi,tthousand USD Aggregate quantityt = Σ Qi,t × factoritonnes Aggregate real valuet = Σ Qi,t × base UVithousand USD at 2014–16 prices
  • The item factor applies to quantity.
  • The factor is 1 for almost every item. Only a limited number use another factor to convert them to a common equivalent, for example rice, milled equivalent, cassava equivalent, some milk groups (cheese, butter and ghee, whey, condensed and dry milk) and some meat groups.
  • An item can belong to more than one group.
  • An item with no data in a year drops out of that year's sum. An item reported with value but no quantity counts in the aggregate value, but not in the aggregate quantity or real value.

Region × item group

  • Sum of the country × item group aggregates over member countries with Aggregation = TRUE.

Base of the aggregate indices

  • The average of the aggregate over 2014–16 — not the sum of the items' own bases. An item or country that enters the group after the base adds to later years but not to the base.

7Data and preparation

  • Source: FAO trade data (June 2026 extract), 2000–2024: import and export quantity and value by country × CPC item × year.
  • Base period 2014–2016 = 100.
  • Values are in thousand USD, quantities in tonnes, unit values in thousand USD per tonne (shown as $/t on the other pages).
Data snapshot. The trade data were extracted in June 2026, so results run up to 2024. They may not match the current data in SWS exactly.

Preparation

  1. Reshape to one row per country × item × year with four columns: import Q, import V, export Q, export V.
  2. Remove live animals (CPC 021…). They are reported in head, not tonnes, so their unit values are not comparable.
  3. Fix one-sided zeros: if Q = 0 but V > 0, Q is set to missing; if V = 0 but Q > 0, V is set to missing. The other side still counts in its own total.
  4. A valid observation is one with Q > 0 and V > 0 — enough to compute a unit value.
No data are filtered. Every record is used as reported, even when the source data look problematic: very small records (Q < 10 t or V < 10 thousand USD), unusual unit values, and estimated, imputed or missing-flagged records all stay in. Records flagged as missing (M) that carry a 0 enter as 0. There is no coverage rule and no minimum number of base years. The other pages of this dashboard flag values for review; they never remove them.

10Decisions on indices and real values, 19 Oct 2026

  • All indices will be produced for aggregates only.
  • Unit value index will not be calculated at all.
  • Real value index will not be calculated at all.
  • We don't filter any data if the source data is problematic.
  • For real values, we will see what happens to other countries when an aggregated output is 10× previous years.
  • A section for UVs will be added to see if there are strange base UVs.
  • Birkan will create a new dashboard upon these decisions.
  • We will try to identify at which aggregate level we will publish these all; it's possible to remove tiny groups.

How the checks work

Applied to every aggregate value index and quantity index value. Flags are for review only — no data are removed.

Reproduction

    Flags

    • Critical  index above or below
    • Warning  index above or below , or a year-on-year change of × or more
    • Index = 0 (no trade) is not flagged.

    Members

    • Country aggregate = its items. Region aggregate = its member countries.
    • The change between the 2014–16 average and the flagged year is split across members.

    Finding the cause — in this order

    • Negligible base: the group's 2014–16 average is below 10 t or 10 thousand USD.
    • Coverage: at least half of the year's total comes from members with no 2014–16 data, or at least half of the base comes from members missing that year.
    • One member: a single item or country explains at least half of the change. Its own pattern is shown.
    • Otherwise the aggregate series itself is split into base / one-off / sustained parts: base vs the level around it (2011–13 and 2017–19), the year vs the surrounding years (±3), and those years vs the level around the base.

    Order of importance

    • Critical before warning → base → coverage → one member → one-off years → sustained change → larger trade (average value of the latest five years).

    Jumps by year

    Every year-to-year change of an aggregate real value, by level and flow (rows) and year (columns). Shading shows the share that is a 10× jump.

    What the other countries did

    Each jump is compared with every other country's real value for the same item group, flow and year (for a region: with its member countries). If they moved too, the cause is probably shared — a change in the item list, a classification or a real world event. If they did not, the cause is in this country's data.

    Start here — most important jumps

    Critical first, then jumps that only real value shows (value stayed put), then jumps where value moved too, then shared jumps; larger trade first. Click a row to see the other countries and the items behind it.

    How the check works

    Rule

    • Critical  the aggregate real value is × or more above, or 1/ or less of, the previous year.
    • Warning  × or more above, or 1/ or less of, the previous year.
    • Only consecutive years with a real value above 0 in both are compared.

    The comparison

    • Country: all other countries with a real value for the same item group and flow in both years.
    • Region: the region's member countries.
    • Shown: their median ratio, the share that jumped 10× in the same direction, and all of them added together.

    Cause — in this order

    • From or to a negligible level: the smaller of the two years is below 10 thousand USD.
    • Other countries moved too: at least 5 countries compared, and at least % of them (3 or more) jumped the same way, or their median moved 3× or more the same way.
    • Only real value jumped: the aggregate value changed less than 3× — quantity or base unit value is the problem.
    • Value jumped too: the trade itself changed, or quantity and value were both recorded on a different scale.

    Cause of each jump

    • The one item behind most of the change (for a region: in the member country that contributed most), shown as quantity × base unit value = real value.
    • Base unit value out of line: its base unit value is 10× or more above or below other countries'.
    • Quantity on another scale: its quantity moved 10× more than its value.
    • The series table also shows the unit value (value ÷ quantity) next to the average base unit value (real value ÷ quantity) every year; a 10× gap is shaded.

    How the check works

    Flags

    • Critical  × or more above or below other countries' base unit value.
    • Warning  × or more above or below other countries' base unit value, or 10× or more above or below the country's own unit value in the other years, or the three base-year unit values differ 10× or more.
    • Other countries = median of the countries whose base unit value is all their own data, at least countries.

    Cause — in this order

    • Taken from a group → Negligible base-year record → Base years disagree → Rebuilt base year off → Base period out of line → Country always differs.
    • Off the country's own other years when only the own-years check fires.
