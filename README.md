# Trade Indices

Value and quantity indices of FAO trade data for item groups (countries and regions), base 2014–2016 = 100.

- **Dashboard:** https://mbirkand.github.io/Trade-Real-Value-and-Indices/results/diagnostics_dashboard.html
- **Code and methodology:** [`Indices/`](Indices/) — see [`Indices/README.md`](Indices/README.md) and [`Indices/METHODOLOGY.md`](Indices/METHODOLOGY.md)

Real values were removed from this pipeline on 5 Nov 2026; they are now calculated on SWS with the new methodology.
The earlier version (real values, base unit values) is in the repository history up to commit `95cbc42` (28 Oct 2026).
